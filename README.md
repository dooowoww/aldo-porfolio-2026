# Aldo Portfolio 2026

Personal portfolio website for Aldo Rajendra Akbar.

## Project
This repository contains a static portfolio website built with HTML, CSS, and JavaScript.

## Structure
- `index.html` — homepage
- `style.css` — shared styling
- `script.js` — site behavior
- `html/` — additional pages
- `css/` — page-specific styles
- `assets/` — images and static media
- `document/` — portfolio documents and PDFs

## Run locally
Open the project in a browser directly or serve it locally with:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
